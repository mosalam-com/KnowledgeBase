## الخدمات (من الموقع — التفاصيل في `services/`)
1. **Web Hosting**: Managed Cloud VPS، Dedicated Server Clusters، Enterprise Container Nodes — بيئات معزولة، SSD، نسخ يومية تلقائية.
2. **IT Services**: System Administration، Zero-Trust Cybersecurity، Network & VPN.
3. **ERP Systems**: Odoo CRM/ERP، Moodle LMS، ربط الأنظمة (Workflow & API Sync).
4. **Front End**: UI/UX، React/Next.js، تحسين أداء.
5. **Back End**: APIs (REST/GraphQL)، تصميم قواعد بيانات، منطق أعمال مخصص.
6. **AI-Ready Foundations**: بنية قابلة لتشغيل الذكاء الاصطناعي (GPU nodes، MLOps).
