# KnowledgeBase — قاعدة معرفة شركة مسلم.كوم

قاعدة معرفة موحّدة تغطي كافة تفاصيل الشركة كشركة استضافة (Hosting). أي قسم بيستخدم المعلومات الموجودة في القاعدة، وفريق التسويق بيشتق منها بياناته — مش قاعدة مستقلة.

## مصدر أساسي جديد
- **الموقع الرسمي mosalam.com** أصبح مصدراً رئيسياً للمعلومات (Home، About Us، Portfolio، Market Research، Blog، صفحات السياسات).
- صفحة **Market Research** تعتبر مرجع ذهبي للأسعار الرسمية 2025 + تحليل المنافسين + آلة حاسبة الـ Real Cost.
- `customers/testimonials.md` يضم قائمة **Portfolio الحية** (~45 مشروعاً بروابط فعلية).
- **ملفات مصدرية جديدة أُضيفت (وثائق رسمية/تاريخية):**
  - `policies/*.docx` — الشروط والخصوصية وقواعد الاستخدام والكوكيز (النسخ الرسمية المعتمدة).
  - `company/` — عدة ملفات تعريف للشركة (مُحدّثة + تعريف أقدم) بالعربي/الإنجليزي.
  - `marketing/` — بحثا سوق (web hosting مصر + technical support عالمياً)، مقارنة أسعار (GoDaddy/Bluehost/مجاني)، سكربتات شهادات فيديو، وخطة قناة يوتيوب.
  > راجعها عند أي تحديث للقاعدة؛ الأُولى للتلخيص في `services`, `pricing`, `policies`, و`company`.

## نظرة على الهيكل

| المسار | المحتوى |
| ------ | ------- |
| `company/` | نبذة الشركة، المهمة والرؤية، الفريق |
| `services/` | خدمة لكل ملف (`hosting.md`, `vps.md`, `dedicated-servers.md`, `saas-hosting.md`, `web-development.md`) — استخدم `template.md` لأي خدمة جديدة |
| `engineering/` | المعرفة التقنية الداخلية: runbooks، إعدادات، أوامر — "كيف ننفّذ" بالخطوات |
| `pricing/` | الباقات والأسعار، العروض والخصومات |
| `infrastructure/` | مراكز البيانات، الشبكة، الأمان |
| `operations/` | العمليات اليومية وسير العمل |
| `policies/` | SLA و الاسترجاع و الشروط |
| `customers/` | نوعيات العملاء، الأسئلة الشائعة، الشهادات |
| `marketing/` | رسائل مشتقة من القاعدة، المنافسون، أفكار محتوى |
| `roadmap.md` | خارطة الطريق والأهداف |

## إزاي تستخدمها
- **لدى أي قسم:** عدّل الملفات المختصة بك مباشرة (مثلاً `pricing/` من المبيعات، `infrastructure/` من التقنية).
- **فريق التسويق:** اقرأ في القاعدة المصدرية (services, pricing, customers, infrastructure) واستخرج منها بيانات `marketing/` الملف.

## قواعد التعديل
- اسماء الملفات والمجلدات بالإنجليزية دائماً، **محتوى الملفات بالعربية**.
- عند إضافة خدمة جديدة: انسخ `services/template.md`.
- عند إضافة عملية تقنية: انسخ `engineering/00-template.md`.
- لأي تعديل: لاحظ التغيير في git حتى يقدر يُراجع.
- **مستبعد نهائياً:** أي معلومات شخصية أو دخل شخصي — هذه القاعدة للشركة فقط.
- **شهادات العملاء:** النشر بالأسماء وإذن كتابي — سجّل الإذن في `customers/testimonials.md`.
