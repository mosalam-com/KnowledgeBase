# تصميم وتطوير الويب (Front / Back End)

### وصف عام
- مشاريع تسليم كامل: تصميم (UI/UX) + تطوير (React/Next.js + APIs) + تشغيل على استضافتنا — مع اتصال مباشر خطوة بخطوة.

### المزايا المقدمة (من الموقع: Front End & Back End)
**Front End Development:**
- UI/UX & Web Design
- تطبيقات React.js و Next.js — خفيفة، متوافقة SEO، سريعة
- تحسين أداء (Performance Optimization)

**Back End Development:**
- تكامل APIs (REST/GraphQL)
- تصميم وضبط قواعد البيانات (Database Design & Tuning)
- منطق أعمال مخصص (Custom Software Logic)

### مناسبة لمن؟
- شركات تحتاج موقعاً كاملاً أو تطبيق ويب متخصص (نموذج Portfolio: شركات حقيقية كثيرة).

### التفاصيل التقنية
- الضابط: SSR/Next.js للـ SEO، تحويل الصور والأداء
- GIT/مراجعات، بيئات اختبار قبل الإنتاج

### التسعير (نموذج حقيقي من عقد First Cosmetics)
- إجمالي المشروع: **45,000 جنيه مصري** (UI/UX 7k + Frontend 15k + Backend 18k + QA 5k) — مدة 35 يوم، دفعات 3 × 15,000
- استضافة شهرية بعد التسليم: **3,000 جنيه/شهر** (إيميلات + نسخ + إدارة سيرفر)
